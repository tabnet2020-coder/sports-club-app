# نظام إدارة النادي الرياضي (نادي اللياقة الذكي) - Vite PWA 🏋️‍♀️

مشروع منظم ومبني باستخدام **Vite** مع دعم كامل لتطبيقات الويب التقدمية (**PWA**)، واختبارات **Jest**، وفحص جودة الكود عبر **ESLint + Prettier**، وتكامل مستمر **GitHub Actions CI/CD** جاهز للنشر على **Netlify** أو **Vercel** أو **Render**.

## التشغيل المحلي
```bash
npm install
npm run dev
```

## الأوامر المتاحة
- `npm run dev` — تشغيل خادم التطوير المحلي (Vite).
- `npm run build` — بناء نسخة الإنتاج داخل مجلد `dist/`.
- `npm run lint` — فحص الكود عبر ESLint.
- `npm run format` — تنسيق الكود تلقائياً عبر Prettier.
- `npm test` — تشغيل اختبارات Jest للوظائف الأساسية.

## النشر التلقائي
ارفع المشروع إلى GitHub واربط المستودع مع **Netlify** أو **Vercel** (ملفا `netlify.toml` و `vercel.json` جاهزان ومعدّان تلقائياً لأمر البناء `npm run build` ومجلد النشر `dist`).
