# نظام إدارة النادي الرياضي (نادي اللياقة الذكي) 🏋️‍♀️

تطبيق ويب تقدمي (PWA) متكامل باللغة العربية (RTL) لإدارة الأندية الرياضية، مزود بنظام تفعيل بالسيريال المرتبط بعنوان IP الجهاز، ونظام تسجيل دخول إلزامي لجميع المستخدمين.

## أبرز المميزات
- **نظام التفعيل بسيريال مرتبط بـ IP الجهاز:** لا يعمل النظام إلا بعد تفعيله بمفتاح تفعيل صالح وربطه بعنوان IP الجهاز.
- **نظام دخول إلزامي لجميع المستخدمين:** شاشة دخول محمية باسم المستخدم وكلمة المرور لجميع الأدوار (الأدمن الرئيسي، المدربات، الاستقبال، المحاسبة).
- **تسجيل شامل للمشتركين:** البيانات الأساسية، حساب BMI، الأمراض المزمنة، الإصابات، قياسات الجسم التفصيلية، المواعيد والمدربة، والجانب المالي.
- **الدخول بالباركود وسجل الحضور:** مسح بالكاميرا أو إدخال يدوي وطباعة بطاقة العضوية A4.
- **التصدير إلى Excel و CSV:** تصدير كامل بيانات المشتركين وسجل الزوار.
- **باركود عنوان النادي والخريطة المباشرة + باركود تثبيت التطبيق (PWA).**
- **سجل زوار محمي بكلمة مرور خاصة.**
