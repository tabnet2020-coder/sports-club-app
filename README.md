# نظام إدارة النادي الرياضي (نادي اللياقة الذكي) 🏋️‍♀️

تطبيق ويب تقدمي (PWA) متكامل باللغة العربية (RTL) لإدارة الأندية الرياضية، مصمم ليعمل بسلاسة على الهواتف والحواسيب مع دعم العمل دون إنترنت عبر التخزين المحلي (`localStorage`) و Service Worker.

## أبرز المميزات
- **واجهة هادئة وعصرية:** أزرار رياضية أنيقة، وإحصائيات فورية (عدد المشتركين، حضور اليوم، الإيرادات والمتبقي).
- **تلميح رياضي يومي:** يتبدل تلقائياً بين الصباح والمساء مع إمكانية التبديل اليدوي.
- **صفحة تسجيل شاملة:**
  - البيانات الأساسية مع حساب مؤشر كتلة الجسم (BMI) تلقائياً.
  - الحالة الصحية والأمراض المزمنة (السكري، الضغط، وغيرها) والإصابات السابقة ومكانها.
  - قياسات أجزاء الجسم بالتفصيل (الذراع اليمنى، الذراع اليسرى، الفخذ الأيمن، الفخذ الأيسر، المؤخرة، الخصر، الصدر، الأكتاف).
  - موعد التمارين (فترة صباحية / فترة مسائية) واسم المدربة.
  - القسم المالي المستقل (قيمة الاشتراك، المدفوع، المتبقي تلقائياً، طريقة الدفع، والملاحظات).
- **الدخول بالباركود وتسجيل الحضور:** مسح بالكاميرا أو إدخال يدوي مع تسجيل الحضور اليومي وطباعة بطاقة العضوية بمقاس A4.
- **تصدير Excel و CSV:** تصدير كامل بيانات المشتركين والقياسات والبيانات المالية إلى ملفات `.xlsx` أو `.csv`.
- **باركود عنوان النادي والخريطة المباشرة:** إمكانية تعديل العنوان كتابةً أو عبر رابط خرائط جوجل.
- **باركود تثبيت التطبيق (PWA):** مع إمكانية طباعة ملصق A4 للتعليق داخل النادي.
- **إدارة المستخدمين والصلاحيات:** تعيين الأدمن الرئيسي وإضافة المدربات وموظفي الاستقبال والمحاسبة (الحساب الافتراضي: `admin` / `1234`).
- **سجل الزوار المحمي:** متابعة جميع الزيارات والأنشطة داخل التطبيق بكلمة مرور خاصة.

## طريقة النشر على GitHub Pages
1. أنشئ مستودعاً جديداً (Repository) على حسابك في GitHub.
2. ارفع جميع ملفات هذا المجلد (`index.html`, `manifest.json`, `sw.js`, `icon-192.svg`, `icon-512.svg`, `README.md`) إلى الفرع الرئيسي `main`.
3. اذهب إلى **Settings** > **Pages**.
4. تحت **Source** اختر **Deploy from a branch** ثم الفرع `main` والمجلد `/ (root)` واضغط **Save**.
5. خلال دقيقة سيصبح التطبيق متاحاً عبر رابط HTTPS ويمكن تثبيته مباشرة على الهواتف عبر مسح الباركود!
